# Loan Data Analysis
Analysis of loan data using Python, Pandas and Matplotlib.
- Loads loan data from CSV
- Calculates the default rate (33.33%)
- Charts loans by status and average loan amount

## Loan Default predictor
Predicts loan defaults using Python and scikit-learn (random forest).
-Uses generated practice data of 1000 loans
-Compares the model against an "always say safe" baseline
-Uses class weights and threshold tuning to catch more defaulters
-Explains the precision vs recall trade-off using loan costs
